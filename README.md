# Car Evolution — VOXY MVP

スマホで時間を動かしながら、VOXYの世代の変化に触れるための最小実装です。

> **Important:** The visible CSS vehicle is an interaction prototype only. It is not a production vehicle asset. The locked production standard is documented in [Definitive Master Policy](docs/architecture/definitive-master-policy.md).

## 起動

```powershell
npm.cmd run dev
```

最初の指の動きでヘッドライトが点灯し、車の形が変わった後に年号が現れます。

## 体験の基準

- 発見が先。説明は後。
- 沈黙を恐れない。
- ユーザーを信じる。
- 時間は、動いたか。
