# AdSense低価値コンテンツ指摘への修正（2026-09-20）

Googleの合否・審査完了日は保証できない。以下は実装・検証の記録であり、審査合格の記録ではない。

## 読者向けの変更

- ホームに車名・代表型式検索。全角英数字、日本語車名、複数条件に対応。型式ごとに世代の候補を表示する。車台番号は収集しない。
- 共通比較30ページに代表寸法の差分と、チェック・質問を書き込んでテキスト保存できる実車確認メモを追加。駐車適合や安全性は判定しない。
- ソリオMA36S前後期、N-BOX JF1前後期、標準タントLA600S前後期、ヴェルファイア20/30に、メーカー資料を踏まえた具体的な確認手順を追加。
- AI制作画像を含むことを比較画像直前・運営情報・制作方針で説明。試乗・分解調査ではないこと、公式資料を優先することを明示。
- 制作方針に9月19～20日の訂正履歴を掲載。

## 事実・出典の修正

- ヴェルファイア20/30：2015年Z AエディションFFの全長を4,930→4,935mm。
  - https://toyota.jp/ucar/catalog/brand-TOYOTA/car-VELLFIRE/201501/10095384/
- アルファード20/30：寸法の比較基準を2008年240S FF（4,865×1,840×1,900mm）と2018年2.5S AパッケージFF（4,950×1,850×1,935mm）へ明確化・訂正。画像自体から測定した数値ではない。
  - https://toyota.jp/ucar/catalog/brand-TOYOTA/car-ALPHARD/200805/10047783/
  - https://toyota.jp/ucar/catalog/brand-TOYOTA/car-ALPHARD/201801/10113530/
- アルファード30/40：全高が一律に拡大する説明を削除し、寸法表の代表仕様と参考画像の仕様を区別。
- N-BOX JF1前後期：初期型の全高1,770mm／オプション装着時1,780mmという例外を追記。
  - https://www.honda.co.jp/auto-archive/nbox/2012/webcatalog/spec/
- ハリアー・タント：配列形式の個別出典が共通描画に無視される不具合を修正。
- プリウス：欠落していた公式カタログへの出典リンクを追加。
- 確認日がない個別出典に日付を生成しない。

## 表示・保守

- 共通比較30ページはデータと描画を分離し、全文を初期HTMLへ生成。同じ描画関数を開発ブラウザにも使用。
- ホームの16車種リンクを初期HTMLへ生成。
- 16車種の初期HTMLへ実際のH1、ヒーロー画像、世代の手がかり、公式参照リンクを生成。空H1と重複H1を解消。
- ページカタログに未登録のローカル3下書きをproduction buildへ含めない。削除はしない。
- sitemapは転送元3 URLを除外し69 URL。転送設定自体は維持。
- 共有キャンセルとクリップボード拒否を処理。

## 検証

- npm run build / npm test（7テスト） / git diff --check：合格。
- 共通比較30ページ：390pxの実ブラウザでH1一つ、横overflowなし、比較画像60枚読み込み、確認メモあり。

- 69 URL：初期HTML、canonical一つ、H1一つ、JSON-LD構文を検査。
- 内部参照1,346件：生成物に対応ファイルあり（出典の追加前の集計）。

## 範囲・判断の限界

- 画像の新規制作・加工・削除なし。全掲載画像の細部・実在グレードが新たに個別監査済みになったわけではない。
- メーカー資料を整理した確認手順と機能の追加は、取材・試乗実績を意味しない。
- 共通比較以外の既存比較ページは今回全文プリレンダーへ移行していない。
- Googleの低価値コンテンツ判定を機械的に再現できない。テスト合格とAdSense承認は別。
- AdSense再審査・GSC登録リクエストはこの作業では送信しない。
