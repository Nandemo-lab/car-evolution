# 車両画像の制作・採用ゲート

CarVistaの画像は装飾ではなく、世代差を判断するための閲覧体験である。新規制作・差し替え・TOP掲載のたび、以下を順番どおりに完了する。どれか一つでも未達なら公開しない。

## 監査済みMaster Asset基準（2026年8月）

既存Master Asset 112点について全件の車両考証・画像品質監査を実施し、その後に個別監査を通過した4点を追加した。現在の監査済みMaster Assetは116点とする。

- 初回全件監査：本番153参照／39 indexページ、ユニーク112点
- 初回判定：A 112／B 0／C 0／D 0、欠損0
- 追加個別監査：合格4点
- 最終判定：全116点を本番利用継続可能

この116点はCarVistaの「監査済みMaster Asset」基準群である。新規ページ制作のたびに116点を全件再監査しない。掲載時は、使用するAssetについて世代、前期・後期、標準／Custom等の仕様、グレード系統およびページ文脈との一致だけを確認する。

個別再監査が必要なのは、次のいずれかに該当する場合に限る。

1. Assetを加工した
2. Assetを再生成した
3. 新しいページで従来と異なる意味・仕様として流用する
4. 公式資料との新しい矛盾が見つかった
5. ユーザーまたはQAから具体的な疑義が出た
6. 車種・世代・前期後期の対応関係を変更した

新規Assetは既存116点とは別に個別監査し、合格後に監査済みMaster Asset群へ追加する。新規ページでは、監査済み既存Assetで成立するか、別用途でも正確に再利用できるかを先に確認し、それでも不足する場合のみ制作する。ただし正確性を生成回数削減より優先し、仕様や世代を誤認させる再利用は行わない。

## 1. 事実を固定する

- 世代、販売開始年、型式、前期・後期、代表グレードを公式資料で確定する。
- 車体色、ホイール、エアロ、エンブレムの扱いを制作前に決める。
- 世代差とグレード差を同じセットに混ぜない。

## 2. カメラ設計を固定する

- 前左3/4、カメラ高1.15m、70mm相当、水平を標準とする。
- 車体の前後端、タイヤ接地線、車体幅の基準位置をセット内で固定する。
- 背景、光源、床反射、トリミング比率も同一にする。

## 3. 制作・車両検品

- 各世代の正確な参照画像を入力にし、灯火類、グリル、バンパー、窓形状、ホイールを保持する。
- 誤ったエンブレム、読めるナンバー、存在しないエアロ・部品は採用しない。
- 世代・前後期・代表グレードの顔が一致するかを、車オタク観点で確認する。
- 確信できない細部は「要確認」とし、公開用セットから外す。

## 4. 比較品質・実装検品

- 3枚を並べ、カメラの左右・高さ、車体幅、タイヤ接地線、前後端位置を確認する。
- 表示倍率補正は、実車の縦横比を変えず、見かけの距離だけを正規化するために使う。
- 最適化済みのプロジェクト内アセットだけを参照する。
- 本番ビルド後にPC・モバイルのスクリーンショットを必ず提示する。
- 承認なく公開しない。
