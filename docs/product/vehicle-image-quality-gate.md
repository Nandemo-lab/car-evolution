# 車両画像の制作・採用ゲート

CarVistaの画像は装飾ではなく、世代差を判断するための閲覧体験である。新規制作・差し替え・TOP掲載のたび、以下を順番どおりに完了する。どれか一つでも未達なら公開しない。

## 1. 事実を固定する

- 世代、販売開始年、型式、前期・後期、代表グレードを公式資料で確定する。
- 車体色、ホイール、エアロ、エンブレムの扱いを制作前に決める。
- 世代差とグレード差を同じセットに混ぜない。

## 2. カメラ設計を固定する

- 前左3/4、カメラ高1.15m、70mm相当、水平を標準とする。
- 車体の前後端、タイヤ接地線、車体幅の基準位置をセット内で固定する。
- 背景、光源、床反射、トリミング比率も同一にする。

## 3. 制作・車両検品

- 各世代の正確な参照画像を入力にし、灯火類、グリル、バンパー、窓形状、ホイールを保持する。
- 誤ったエンブレム、読めるナンバー、存在しないエアロ・部品は採用しない。
- 世代・前後期・代表グレードの顔が一致するかを、車オタク観点で確認する。
- 確信できない細部は「要確認」とし、公開用セットから外す。

## 4. 比較品質・実装検品

- 3枚を並べ、カメラの左右・高さ、車体幅、タイヤ接地線、前後端位置を確認する。
- 表示倍率補正は、実車の縦横比を変えず、見かけの距離だけを正規化するために使う。
- 最適化済みのプロジェクト内アセットだけを参照する。
- 本番ビルド後にPC・モバイルのスクリーンショットを必ず提示する。
- 承認なく公開しない。
