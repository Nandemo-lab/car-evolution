## 承認後の設定

1. A8の提携承認、広告素材、リンク先、成果・否認条件、広告掲載面の規則を再確認する。
2. `src/affiliate.js` の該当する `affiliateDestinations.usedCarSearch` または `.valuation` だけを設定する。`partner` はGA4で案件を識別する小文字英数字とアンダースコアのID。広告URLを加工せず、A8発行のHTTPSリンクをそのまま設定する。

```js
usedCarSearch: {
  partner: 'a8_s00000001263004',
  status: 'approved',
  enabled: true,
  url: 'A8から承認後に取得した正規の広告URL',
},
```

3. 広告がファーストビュー等で明確に広告と分かるか、スマホ表示、`rel="sponsored noopener noreferrer"`、実際の遷移先をプレビューで確認する。クリックや成果を人為的に発生させる試験はしない。
4. 本番公開は別途OWNER承認後。公開した広告掲載URLはA8の広告掲載URL管理へ提出する。案件終了・提携解除時は `enabled: false` にして広告を非表示にする。

現時点の `affiliateDestinations` は両方とも `null` なので、未承認広告は本番・プレビューに表示されない。

## 計測

GA4で `view_comparison`、`open_related_comparison`、`click_used_car_search`／`click_vehicle_valuation` を確認する。クリックイベントにはページ（`comparison` または `page_path`）と `partner` が付く。これらは**広告クリック**であり、A8の成果発生・確定報酬ではない。A8のプログラム別レポートと突き合わせ、発生・確定・否認を別々に扱う。
