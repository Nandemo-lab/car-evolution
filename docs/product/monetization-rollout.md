## 承認後の設定

1. A8の提携承認、広告素材、リンク先、成果・否認条件、広告掲載面の規則を再確認する。A8公式ヘルプは、テキスト素材の文言変更やコードからリンク部分だけを抜き出すことを禁止している。正規素材のタグ全体（1px計測画像を含む）を無改変で掲載する。
2. `src/affiliate.js` の該当する `affiliateDestinations.usedCarSearch` または `.valuation` だけを設定する。`partner` はGA4で案件を識別する小文字英数字とアンダースコアのID。`creativeHtml` にA8発行の正規広告コードをそのまま指定する。

```js
usedCarSearch: {
  partner: 'a8_s00000001263004',
  status: 'approved',
  enabled: true,
  creativeHtml: 'A8から承認後に取得した正規の広告コード全体',
},
```

3. 広告が明確に広告と分かるか、スマホ表示、A8が許可する `rel` 属性の扱い、実際の遷移先をプレビューで確認する。A8のタグ内の属性を自己判断で追記しない。GA4イベントはタグを改変せず外側の要素で計測する。クリックや成果を人為的に発生させる試験はしない。
4. 本番公開は別途OWNER承認後。公開した広告掲載URLはA8の広告掲載URL管理へ提出する。案件終了・提携解除時は `enabled: false` にして広告を非表示にする。

2026-11-28、カーネクストのA8発行テキスト素材ID 016（「カーネクスト」および1px計測画像）を `affiliateDestinations.valuation.creativeHtml` に改変せず登録し、`enabled: false` とした。掲載承認後にこのフラグだけ有効化する。対象はノア、VOXY、タントの車種ページと関連する3比較ページに限定し、購入・売却を問わない全ページへの機械的な挿入はしない。ガリバーとソコカラは引き続き審査中で未設定。A8の素材コードをクリック試験することはしない。

## 計測

GA4で `view_comparison`、`open_related_comparison`、`click_used_car_search`／`click_vehicle_valuation` を確認する。クリックイベントにはページ（`comparison` または `page_path`）と `partner` が付く。これらは**広告クリック**であり、A8の成果発生・確定報酬ではない。A8のプログラム別レポートと突き合わせ、発生・確定・否認を別々に扱う。
