# CarVista Phase 4 コンテンツポートフォリオ（2026-10-20）

## 評価方法

sitemap掲載73 URLからTOPとTrust 4 URLを除いた68コンテンツURLを対象にした。共通ナビゲーション、Trust導線、免責、フッターを除去した本文について、H1、主要画像、外部根拠、本文量、8文字単位の類似度を機械確認し、最弱ページは実際の本文も確認した。

文字数だけではKEEPにせず、ページ固有の型式・改良境界・判別点・代表仕様・中古車確認方法・公式根拠の組み合わせが検索意図に答えるかで判定した。

## 判定集計

- KEEP：32 URL
- REBUILD：35 URL
- MERGE候補：1 URL
- 合計：68 URL

## REBUILD（35）

34件の世代／前後期比較ページでは、各車両画像の直下に、そのページの既存公式考証から得た固有の判別点を結び付けた。共通チェックフローではなく、左右それぞれの画像で見る箇所が異なる。対象は `src/data/comparisons/` の34データに対応する公開URLすべて。

追加の1件は `/voxy-70-80-90.html`。70・80・90系の型式確認に使ったトヨタ公式の中古車情報、旧車情報、現行WEBカタログをページ内へ明示した。

## KEEP（32）

- 車種歴代15 URL（ESQUIREを除く）：各世代の画像、型式・期間、世代固有の転換点、公式根拠がある。
- 兄弟・競合比較6 URL：Phase 2で代表仕様、比較条件、購入判断、公式根拠を個別整備済み。
- 独自構成11 URL：N-BOX／ALPHARDの型式判別、個別の前後期ガイド等。検索意図が比較データ34件と重ならず、固有の確認手順を持つ。

機械監査で最短だった `/cars/spacia.html` も、MK32S・MK53S・MK94Sの期間・型式・世代別変化、関連比較、公式根拠を持つため、文字数だけを理由にREBUILDしなかった。

## MERGE候補（1）

- `/cars/esquire.html` → `/compare-voxy-noah-esquire.html`

ESQUIREは1世代のみで「歴代」意図が狭い。一方、2017年7月改良、ZRR80G／ZRR85G／ZWR80G、Xi／Gi、ガソリン／ハイブリッドの確認価値は現URLに残る。検索実績・被リンク・統合先の情報包含を確認し、本人承認を得るまでURL変更、削除、noindexは行わない。

## 再発防止

`npm run audit:content` はsitemap掲載68コンテンツURLだけを再帰的に監査し、次を失敗条件にする。

- ページ固有本文が900文字未満
- H1が1件でない
-主要画像または外部根拠がない
- 最も似た別ページとの本文8-gram類似度が0.82を超える

`tests/content-tools.test.js` は34比較ページすべてで、画像カード数と「画像で見る場所」の数が一致し、空の判別点が生成されないことを検証する。
